# YKS Çalışma Köşesi

Coğrafya ve Biyoloji için kısa, okuyarak çözülen YKS tarzı sorular. Telefondan rahat kullanılır, yanlışlarda dipnot gösterir.

## Düzenleme
- `config.js`: karşılama ismi ve motivasyon notları
- `questions.js`: sorular, konular ve dipnotlar (dosyanın başında yeni soru ekleme şablonu var)

## Yayınlama
GitHub: Settings → Pages → Deploy from a branch → main / (root)
